# 蓝色失重 · 动作研究 01

这是早期八帧动作设计原型，保留用于研究对比。四种泳姿各 16 帧的完整实现
现位于 `../../wallpapers/blue-weightless/`；本页不代表当前完整实现的帧数和节奏。
人物的短深蓝发、珊瑚色泳镜、深蓝薄荷条泳衣和原有成年形象继续保留。

## 当前问题与处理方向

正式版 `character.js` 为每种泳姿使用一张完整原画，借助小幅连续网格形变运动。
它保护了脸、手指和脚趾，却无法表达手臂完整划水、前后遮挡、肩髋滚转和换气。
继续加大原图的形变幅度会拉扯关节，不能代替重新绘制动作关键姿态。

本原型包含自由泳八个完整人物姿态、原版/新稿同步对比、暂停、逐帧前后查看、
速度选择、水面开关和姿态缩略图。新稿按关键帧切换，不使用双人物交叉淡化来掩盖跳帧。
减少动态效果时默认暂停，页面隐藏时停止推进时间。

从仓库根目录运行 `python -m http.server 8080`，打开
`http://localhost:8080/prototypes/blue-weightless-motion/`。
只运行在本机检查，不发布公共站点。

## 关键姿态稿的已知待修项

- 已将多数帧的抬头姿态改为低头前进，仅在回臂阶段侧转换气。
- 现有八帧仅用于研究姿态覆盖，帧数不足以交付流畅的循环动画。
- 不同图之间躯干长度、肩髋位置和腿部轮廓还需统一注册，不能只按画框居中播放。
- 近侧/远侧手臂的归属和遮挡仍需逐帧校准，特别是前伸、交替和首尾衔接。
- 手指、腕部角度、肩关节、脚趾轮廓需要在最终尺寸和放大视图复核。
- 水面开关仅显示辅助观察线，默认关闭；头部与水面的实际高度和入水遮挡尚未整合。
- 最终绘制需按同一骨架和关节点补齐中间帧；本页的简单逐帧预演不能视为最终效果。

原始生成文件保留在生成目录；仓库内 `assets/freestyle-keyposes.png` 是第二轮低头/换气校正稿。

## 四泳姿设计约束

以下周期长度是为舒缓壁纸设定的设计初值，不是从《Free!》逐帧测得的数值。

| 泳姿 | 主要节奏 | 身体与呼吸 | 暂定完整周期 |
| --- | --- | --- | --- |
| 自由泳 | 入水前伸 → 抱水 → 推水 → 高肘回臂；两臂交替 | 肩带带动滚转，侧转换气后回水，双腿交替小幅打水 | 约 2.4 秒，含左右手各一划 |
| 蛙泳 | 外划内收 → 前伸 → 蹬夹 → 保留滑行 | 换气随划水抬肩，蹬腿推进后收成流线型，不把手脚同步乱摆 | 约 2.6 秒 |
| 仰泳 | 出水 → 过肩回臂 → 入水 → 水下推水；两臂交替 | 头稳定，肩带滚转，持续小幅打腿，手臂真实经过头顶 | 约 2.4 秒，含左右手各一划 |
| 蝶泳 | 双手入水 → 抱水推水 → 双臂低平回摆 | 一次划臂两次打腿，胸到髋腿传波，头先于手回水，避免整个身体机械上下弹跳 | 约 2.2 秒 |

动作确定后，再让前进速度、气泡、入水飞溅和尾流跟随真实发力时刻。
跳水和上岸也需独立动作链：蹬离池沿—腾空—指尖入水—流线滑行；
扶梯/池沿支撑—抬髋—迈步—站稳，不能仅旋转或平移原画。

## 研究来源与使用范围

- [《Free!》官方公开影像入口](https://fs.iwatobi-sc.com/movie/)：作为后续动作节奏、镜头与水花的视觉研究入口。
  当前没有为具体镜头做时间码标注，不能把本稿称为某个镜头的逐帧复现。
- [USMS 自由泳身体位置与滚转](https://www.usms.org/fitness-and-training/guides/freestyle/body-position)：核对身体轴线、肩髋滚转与回臂关系。
- [Swim England 四种泳姿](https://www.swimming.org/learntoswim/learning-the-four-swimming-strokes/)：核对蛙泳划水、换气、蹬腿、滑行的先后顺序。
- [USMS Master Butterfly](https://www.usms.org/fitness-and-training/articles-and-videos/articles/master-butterfly)：核对双臂同步、身体波动、每划两次打腿和头部先回水。
