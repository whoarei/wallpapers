FOUR STROKES / 四种泳姿的动作方向

每种泳姿，都要有自己的呼吸。

01

自由泳

高肘回臂、左右交替，肩髋随划水转动。换气时侧转，随后低头回水。

伸展 → 抱水 → 推水 → 回臂
02

蛙泳

划水抬肩换气，收腿后蹬夹，再伸展滑行。把“发力—停留”的节奏做出来。

划水 → 换气 → 蹬夹 → 滑行
03

仰泳

双臂交替过肩回摆，肩带随身体转动；头保持稳定，打腿小而连续。

出水 → 过肩 → 入水 → 水下推水
04

蝶泳

双臂同步回摆，波浪从胸部传向髋腿；一轮划臂配两次打腿，头先于手回水。

入水一踢 → 抱水 → 推水二踢 → 回臂
