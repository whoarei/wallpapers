悬浮字形

桌面支持启停、删除文字和调整字号。添加、编辑或导入文件，请在壁纸盒子的预览中操作，再导出已配置壁纸并导入。

当前使用主程序的共享配置。编辑或导入请打开主程序或托盘的「壁纸设置 → 矩阵回声」，保存后会通知所有使用这张壁纸的屏幕。预览中仍可查看和导出备份。

诗词库

添加诗词

每行填写一次完整展示的诗句或句联，保留标点；每行最多 120 字。

恢复内置诗词的原文与启用状态？个人新增诗词会保留。

新增诗词保存在本地。可导出仓库文件，将其中的 JSON 加入 content/poems/，下次发布自动带入。导入按 id 合并，文件出错时整批保持原样。

悬浮文字库

当前分类还没有文字，可添加或导入 JSON。

添加悬浮文字

每条填写一个汉字、完整彝文音节或藏文字母；注释最多 600 字。保存时会检查所选字体是否包含该字形。

恢复内置悬浮文字的注释与启用状态？个人新增文字会保留。

文字和注释保存在本地。导入按 id 合并；任意文件无效时整批保持原样。「导出文字仓库 ZIP」中的单条 JSON 可加入 content/glyphs/，下次发布自动带入。
