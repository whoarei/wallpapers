# 扩充悬浮文字

每条悬浮文字对应一个 JSON 文件。小篆、楷书、彝文与藏文都使用同一格式；
字符和点击后显示的注释一起保存。当前包含 60 条内置记录。

```json
{
  "script": "seal",
  "character": "鹿",
  "reading": "lù",
  "description": "鹿科动物，常见于山林。",
  "enabled": true
}
```

`script` 可选 `seal`（小篆）、`kai`（楷书）、`yi`（彝文音节）、
`tibetan`（藏文字母）。`character` 必须是该类型中的一个完整字符；
藏文元音附标不能单独作为悬浮字。`reading` 选填，最多 80 字；
`description` 必填，最多 600 字，可使用 `\n` 分段；`enabled` 默认 `true`。

`id` 可省略，默认由类型和字符生成，例如上例为 `glyph-seal-9e7f`。
修改已有记录时，保留导出文件里的 `id`，导入会更新该条记录。
同一字形类型中的字符不可重复，不同类型可使用相同汉字。

## 在壁纸中添加

1. 在预览或普通浏览器中打开「诗词与文字 → 悬浮文字库」。
2. 使用「添加文字」，或通过「导入文字 JSON」导入单条对象、对象数组或多个 JSON 文件。
3. 可编辑字符、注释，启停或删除记录。恢复内置文字会保留个人新增记录。
4. 「导出文字 JSON」用于备份；「导出文字仓库 ZIP」提供逐条 JSON 文件。
5. 要在桌面应用个人配置，使用「导出已配置壁纸」，再在壁纸盒子的「设置 → 导入壁纸」中导入 ZIP。

导入按 id 合并；任意文件无效时整批保持原样。最多 500 条记录（包含可恢复的
内置记录），单次导入总大小不超过 2 MiB。本地增补随同设置保存，后续正式版
更新继续保留；预览和各显示器的数据目录彼此独立。

## 通过仓库发布

将上例保存为此目录下的 `seal-deer.json`，提交后即可随下次发布进入壁纸包。
每个文件保存一个对象，建议使用小写英文、数字和连字符命名。
打包会自动收集所有 `content/glyphs/*.json`，检查格式、重复记录与字体覆盖，
重新生成包内的离线数据，无需修改 JavaScript。

本地直接预览源码时，先运行：

```sh
python scripts/sync_matrix_glyphs.py
```

`glyphs.generated.js` 为生成文件。导入和仓库打包都按实际随包字体校验字符；
不支持的字形会报告错误。小篆字体包含 4,752 个常用字形，楷书及彝文使用
完整随包字体，藏文使用随包字体覆盖的基本字母。扩充字体时保持 WOFF 1 格式，
保留来源与授权文件，并重新生成预览数据；不能在 JSON 中指定外部字体或脚本。
