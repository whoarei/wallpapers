# 矩阵回声

底层保留三层代码雨与光门。前景独立绘制小篆、楷书、彝文音节文字、
藏文字母，以 1–3 倍字号缓慢悬浮、淡入淡出，不占用底层字符的位置，
不跟随代码雨下落，并避开光门、门框及其辉光，预留字号与漂移空间。
完整诗句从画面上方逐字进入，接续所在字节流的现有位置与速度，
首字领头向下流动，后续文字向上连续排列，不在画面中途整句出现。
较长句子按从右向左的顺序分到相邻字符列，每列仍由首字领头，
保留所有文字与标点。诗句占用原有字节流的位置，字号、流速、辉光及
点击涟漪与所在字符流一致；只保留特色字的独立悬浮效果。

点击悬浮字可打开注释卡片，显示小篆或楷书对应的汉字、读音与简短释义，
或彝文的音节名、藏文的字母名及文字说明。音节、字母不作固定汉语词义的意译。
阅读时保留所选字形，背景继续流动；点击空白处或关闭按钮收起注释，
有键盘的环境也支持 Tab、Enter 与 Escape。注释在离线和桌面转发点击模式下均可用。

「诗词与文字」面板提供「诗词库」与「悬浮文字库」两个标签。悬浮文字可添加、
编辑、启停、删除、恢复内置记录，支持单条、多条和多文件 JSON 导入，以及 JSON
备份和逐条仓库文件 ZIP 导出。恢复内置记录保留个人新增文字；后续正式版
更新继续读取个人增补。导出的已配置壁纸同时包含诗词、悬浮文字、注释与离线字体。
小篆字体已扩充至 4,752 字，所有新增记录按实际字体覆盖校验，避免缺字方框。
新增 JSON 随下次发布自动带入，格式和操作见 [悬浮文字扩充说明](content/glyphs/README.md)。

在壁纸盒子 **v0.12.0 或更新版本**，打开主程序或托盘的
**「壁纸设置 → 矩阵回声」**，即可分别开关诗词和悬浮文字、选择字形、调整字号，
设置流速与辉光，并添加、编辑、启停、删除或批量导入作品和文字注释。
设置页沿用主程序的浅色紧凑样式，直接呈现设置项；容量、配置状态和长说明默认收进「配置详情与说明」。
新增或编辑诗词、文字后点击「完成编辑」，再点击底部唯一的主操作「保存更改」。
内容区单独滚动，保存栏始终占位，不覆盖最后一项内容；支持旧宿主约 574×209 的区域及 320×180 小尺寸。
基础样式随壁纸包离线提供，兼容正式 v0.12.0；新主程序的「展开编辑」可提供更大的编辑空间。
主程序持久保存配置，同一壁纸的各屏幕与预览共享；正在运行时收到更新，
未运行时下次启动读取。配置投递不会恢复已暂停的动画。
恢复内置作品会保留个人新增诗词。
初始库包含王维、张九龄、杜甫、李白、王之涣、苏轼的六首作品。

设置页支持单条、数组和多文件 JSON 导入，按稳定 ID 更新；一批文件中
任意文件无效时整批回滚。单次导入最多 500 首、2 MiB，主程序保存的完整
配置另有 **32 KiB（UTF-8）** 上限，容量位于配置详情，超限时自动展开并提示精简后再保存。
内置内容只保存修改和删除状态，不重复写入原文。保存冲突或失败时保留草稿，
重新载入会以主程序当前配置替换草稿，不自动重试覆盖。
播放页的「诗词与文字」用于查看与导出 JSON、仓库文件 ZIP 或已配置壁纸。
原先预览中的本地增补不会被删除；可先导出 JSON，再到新设置页导入一次。

旧版宿主和普通浏览器继续使用本地配置；预览中支持添加、编辑和文件导入，
桌面仍提供无需键盘的操作。「导出已配置壁纸」生成含个人诗词、设置和字体的 ZIP，
可在壁纸盒子的「设置 → 导入壁纸」中应用。导出的配置首次加载时
写入该环境的本地设置，此后同一浏览器数据目录中的正式版升级继续
保留个人增补；预览、各显示器使用各自的浏览器数据目录。
无法访问本地存储时仍可临时使用，并在面板提示导出备份。

全部字体随包离线使用，来源、字形处理与授权见 [fonts/NOTICE.md](fonts/NOTICE.md)。
优先加载真实字体，加载失败的悬浮字形不会用系统字体代替。
诗句随代码雨流速一起变化，完整移出画面后再轮换；作品署名保留在
管理列表与无障碍文本中。用户暂停、宿主暂停及页面隐藏时停止，
恢复时不跳过诗句。减少动态效果偏好下，悬浮文字保持静止。

通过 GitHub 添加诗词见 [content/poems/README.md](content/poems/README.md)。
