所有场景都在 DOM 就绪后初始化，兼容直到 `DOMContentLoaded` 才出现的旧模式标识。不依赖 `__SCREEN_GARDEN_*` 私有函数，不修改宿主对象，也不要求宿主根据壁纸名称、DOM 或类名增加特例。

## 共用代码与离线包

`scripts/wallpaper-runtime.js` 是共用源码；每个壁纸目录带有相同的 `wallpaper-runtime.js`，使用相对路径加载。这样源码目录和单个 ZIP 均可独立运行，无需访问仓库父目录或 CDN。修改共用源码后执行：

```sh
python scripts/sync_runtime.py
python scripts/sync_runtime.py --check
```

适配层负责能力检测、声明式控件显示、暂停快照与事件、时钟任务管理及可选操作的校验/去重。场景仍负责自身模拟、绘制、交互、帮助文案与恢复时钟。控制栏不会把按钮点击传到场景中；所有场景操作继续使用标准 DOM 输入及原有画布坐标变换。

可选操作同步返回 JSON。它们检查当前实例、暂停、容量，缓存最近 128 个有效请求的成功或失败结果；同一请求更换动作会被拒绝。仅水族箱的 `feed` 明确允许在仅因遮挡而暂停时更新食物状态，恢复后呈现；其余操作在遮挡时禁用。手动、系统或页面暂停始终禁止这些操作。

## 验证

```sh
python -m unittest discover -s tests -v
node tests/blue-weightless.test.cjs
node tests/zenith-sky.test.cjs
node tests/ocean-climate.test.cjs
BROWSER_PATH=/path/to/chromium node tests/wallpaper-adaptation.browser.cjs
python scripts/build.py
```

浏览器适配检查覆盖 10 张壁纸 × 6 种环境：独立浏览器、v1 预览、v1 桌面、旧模式标识、不支持的协议版本、缺少鼠标移动能力的桌面。检查初始系统暂停、暂停/恢复、页面暂停保留、可选操作的成功/失败/去重/淘汰/实例切换、合成点击不触发背景、控制栏唤回及 390×844、320×480、800×450 的控件命中。

默认宿主为明确标注的模拟对象。可设置 `WALLPAPER_HOST_WRAPPER` 为已配置并执行的真实宿主初始化脚本，复用同一检查；桌面分支改用该脚本的输入、暂停和操作入口。`WALLPAPER_ROOT` 可指向按壁纸 ID 分目录解压的包，验证 ZIP 内的实际文件。测试阻断外部网络；水族箱的适配矩阵跳过 Canvas 栅格化，完整绘制及长期鱼群/鲨鱼行为由 `tests/aquarium.browser.cjs` 单独检查。

现有水族箱、海底互动、海底巡游、天气设置、游泳动作与星空导出浏览器检查同时用于回归。浏览器检查可证明页面逻辑和真实宿主 JavaScript 的组合行为，不能代替 Windows Explorer 的图标过滤、鼠标穿透、负坐标副屏、混合 DPI 和任务栏工作区实机验收。

本次验证结果：10 个解压后的 ZIP 共 60 组适配场景通过，包括禁用全屏后的帮助文案检查；v0.10.0 实际宿主 JavaScript 的输入、暂停与操作组合检查通过；28 个 Python 单元测试、星空与游泳逻辑测试，以及上述 6 套浏览器回归通过。所有包均通过 SHA-256 校验。CI 已加入独立的打包后浏览器检查，保存报告和截图，发布任务须等待它与原有构建检查同时成功。

## 兼容与发布

v1 能力均为可选增强，未提供宿主时仍可运行；仅有旧模式标识时不承诺键盘、全屏、移动或公开暂停状态，控制栏保持可见。旧宿主仍可能强制覆盖页面样式，内容包无法消除这种宿主行为。v0.10.0 起，水族箱的主程序投喂入口依赖新版包声明的 `feed`，旧包仅保留自己的页面投喂入口。

本次适配随壁纸库 1.14.0 分发，以正式版 1.13.0 为基线。静水之间为 1.5.0、松风镇为 1.1.0、蔚蓝漫游为 1.3.1、蓝色失重为 1.1.2，其余六张为 1.0.1。最低程序版本不变，v1 操作仅在宿主声明支持时启用。发布会重新生成 ZIP、清单、大小与校验值，并通过既有 `--previous` 防覆盖检查，不覆盖旧版本内容。程序仓库的内置快照也需在其自己的更新流程中同步，本仓库的源码修改不会静默替换用户已安装的包。

## 新增：矩阵回声（壁纸库 1.15.0）

`wallpapers/matrix-echo/` 使用同一份离线运行时，提供三层代码雨、门与人物剪影、点击数据涟漪、三档流速与辉光，以及页面暂停。公开操作为 `speed` 和 `light`，控件及快捷键按宿主能力显示；只有支持移动唤回的环境允许控制栏淡出。宿主、后台与页面暂停停止动画，恢复重置计时，不补跑暂停时长。

六种模拟环境的离线浏览器适配检查通过，包括 320×480、390×844、800×450 控件命中、初始暂停与恢复、用户暂停保留和控制点击隔离。另验证了流速、辉光、画布涟漪及空格暂停。新增模块版本为 1.0.0，随壁纸库 1.15.0 分发，其余壁纸包保持原版本及原字节；此记录不代表 Windows 桌面实机验收。
